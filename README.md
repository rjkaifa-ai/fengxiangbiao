# 风向标 · 发行包

**版本：v1.0.8　发布日期：2026-11-10**

软件名「风向标」——一套「多平台爆贴监测＋图墙」系统：在 Facebook、YouTube、Instagram 等平台持续搜集正在热推的短视频爆贴，存进你自己的 Google 表格，再生成一面可以筛选、排序、点开就播的图墙，当作内容选题与引流的参考向导。配套的控制台让你不用改代码、直接在页面上调门槛、名单、红线和班次时间——所有设定都写在你自己的表格里。

## 安装方法

你不需要自己敲命令。在**你自己的 Muse** 对话里，把发行包的压缩包（zip 文件）当作附件原样上传（不用解压），然后对它说这一句原话：

> **帮我按发行版装一套《风向标》**

它会按 `docs/给MUSE.md` 一步步执行：连接你的 Google 账号 → 建好或补齐你的数据表 → 建缩略图文件夹 → 把控制台和图墙装好并发布 → 逐项验收。中间只有连接账号、发布链接这类需要你本人确认的步骤会找你点一下。

装好之后，你会得到三样东西：一张你自己的数据表、一个控制台页面、一面你自己的图墙（带发布链接）。日常调整都在控制台里点，设定即时写回你的表格；巡检班次会按你设的时间自动搜集、上墙。

手动安装与每一步的细节，见 `docs/安装说明书.pdf`（或 `.md`）。

## 目录说明

- `wall/`：图墙本体。纯静态单文件，部署到任何静态托管即可；文件顶部 `CONFIG` 里的 `SHEET_ID`、`SETTINGS_GID` 是唯一的实例配置，安装时由 Muse 填入你的值。
- `console/`：控制台本体。`client/` 是页面，`server/` 是读写表格的服务端动作，`drizzle/` 是它自带小数据库的迁移。包里不含依赖（node_modules）与构建产物，安装时由 Muse 按 `package.json` 现装现建。
- `sheet-template/`：建表蓝本。所有页签都只给结构：数据类页签（爆贴主库、新闻时事、风土文化、宗教活动、营销思维、巡检名单-外部、数据统计、播放量快照、趋势数据、单帖趋势）只有表头；配置类页签里平台设定、搜索方式带预置内容，语种设定、国家设定、内容类型、形式设定、红线清单只有表头，监测设定、班次与数量、搜集门槛只有键名、值留空。安装时接你自己的现成表格，已有的配置会被自动读入沿用，没预置的（语种、国家、内容类型、形式、红线）在控制台各节自行添加。国家清单存「国家设定」页，与控制台双向同步。
- `docs/`：说明书与给 Muse 的执行手册。

## 干净包声明

**这是一个干干净净的发行包。** 它不包含任何现成使用者的数据：没有帖子记录、没有巡检名单（只有一行教填法的示例行）、没有账号与密码、没有真实的表格 ID、文件夹 ID 或发布链接。控制台里所有账号默认「未连接」，图墙的内置快照为空，表格模板只给结构（表头与设定键名），配置里只有通用预置：平台（3 个）、搜索方式（一批方法）是随包的现成配置；语种、国家、内容类型、红线清单、门槛数值不预置，以你自己的表格为准。

新用户拿到这个包，装出来的是完全属于自己的那一套：自己的账号、自己的表格、自己的图墙，数据从零开始攒，与任何人互不相通。
